# CelestialWake Studios

The official website for **CelestialWake Studios** — a home for side projects, experiments, and products built with care.

🌐 **Live site:** [celestialwake.com](https://celestialwake.com) *(or your GitHub Pages URL)*

---

## About

CelestialWake Studios is an indie software studio focused on building things that are both useful and enjoyable. This repository contains the source code for the studio's site, featuring a dark theme designed to be easy on the eyes.

## Pages

- **Home** (`index.html`) — Landing page with studio branding and primary navigation
- **Products** (`products.html`) — Showcase of current products
- **About** (`about.html`) — About the developer and ways to connect

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom styling with glassmorphism effects (`backdrop-filter`, layered gradients)
- **GitHub Pages** — Static hosting

No frameworks, no build step — just the fundamentals.

## Local Development

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/jeffdecker/celestialwake-site.git
cd celestialwake-site
open index.html
```

For live reloading, you can use any static server. For example, with Python:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
